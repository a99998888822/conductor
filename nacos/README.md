
### nacos相关逻辑

###### 模块导入
```shell
# 添加模块文件后，在根目录settings.gradle添加：
include 'nacos'
# 然后点击reload all gradle project即可
```

###### nacos 特性
```text
1、配置管理（nacos自己的配置）
    - 配置文件读取
    - 配置验证与默认值
2、服务注册与发现中心
    - 实现服务注册接口
    - 提供服务发现功能（默认加权随机）
    - 支持健康检查和心跳机制
3、配置中心
    - 支持配置的动态获取和更新
    - 实现配置变更监听
    - 提供配置缓存机制
```
